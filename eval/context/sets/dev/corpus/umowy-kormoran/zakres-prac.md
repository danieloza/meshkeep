# Zakres prac: sklep internetowy Księgarni Kormoran

## Etap 1

- Katalog produktów z wyszukiwarką i filtrami (autor, wydawnictwo, kategoria, cena).
- Koszyk i składanie zamówień bez rejestracji oraz z kontem klienta.
- Konto klienta: historia zamówień, adresy, zgody.
- Płatności online przez operatora płatności.
- Integracja z hurtownią: stany magazynowe i ceny z pliku CSV.
- Panel administracyjny: zamówienia, zwroty, treści stron informacyjnych.
- Newsletter: zapis i eksport adresów.

## Poza zakresem etapu 1

- Program lojalnościowy.
- Aplikacja mobilna.
- Wersje językowe inne niż polska.
- Odbiór osobisty w księgarniach.

## Etap 2 (wstępnie)

- Połączenie z API hurtowni zamiast pliku CSV.
- Rekomendacje książek na podstawie historii zakupów.
- Program lojalnościowy z punktami za zakupy.
- Karty podarunkowe.

Zmiany zakresu wymagają aneksu albo pisemnego zlecenia zmiany podpisanego przez obie strony.
