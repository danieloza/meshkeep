# Onboarding

Welcome. This page gets a new developer from zero to a first merged change.

## Access

- VPN profile: ask Tomek. It is needed for staging and for the database replica.
- Repository access: ask Marek.
- Staging credentials live in the team password manager, in the "Kormoran" vault. Never paste them into chat.

## First week

1. Set up the project locally with the README.
2. Read the architecture page and the runbook.
3. Shadow the person on call for one day.
4. Pick a ticket labelled "good first task".

## Code review

- Every change needs a pull request.
- A change to the payments module needs two approvals. Everything else needs one.
- Reviews are expected within one working day.

## Working hours

Core hours are 10:00 to 15:00. Outside them everyone plans their own day. Stand-up is at 10:15 and takes ten minutes.
