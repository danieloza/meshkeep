# Postmortem: stock levels wrong after launch

Date: 19 May 2026
Duration: 3 hours 20 minutes, from 03:05 to 06:25
Severity: high

## Impact

214 products showed more stock than the warehouse had. 38 orders had to be partly cancelled and refunded.

## Root cause

The nightly warehouse import ran twice at the same time. A second worker had been started for the launch, and both picked up the same file. Each run added the delivered quantities on top of the other.

## Detection

The warehouse flagged impossible quantities at 05:40.

## Fix

The import was stopped, the stock levels were rebuilt from the file, and the affected customers were contacted. The import now takes a database advisory lock, so a second run exits at once.

## Action items

- Take an advisory lock in every scheduled job (owner: Marek, done in 1.0.1).
- Compare imported totals with the previous night and stop when they differ by more than 20% (owner: Tomek).
