# Harmonogram realizacji (14 tygodni)

| Tygodnie | Prace |
| --- | --- |
| 1–2 | Warsztaty z fundacją, analiza treści, mapa serwisu |
| 3–6 | Projekt graficzny, makiety, test z trzema darczyńcami |
| 7–12 | Programowanie: treści, darowizny, kalendarz wydarzeń |
| 13 | Testy, poprawki dostępności |
| 14 | Wdrożenie i szkolenie redakcji |

## Założenia

- Fundacja dostarcza teksty i zdjęcia do końca 6. tygodnia.
- Operator płatności podpisuje umowę z fundacją przed 7. tygodniem.
- Każdy tydzień opóźnienia w dostawie treści przesuwa wdrożenie o tydzień.

Start prac jest możliwy dwa tygodnie po podpisaniu umowy.
